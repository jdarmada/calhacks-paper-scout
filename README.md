# Build an Agent That Does the Research

Elastic's Cal Hacks workshop for the **Find the Signal with Elasticsearch** challenge. Get started at https://ela.st/calhacks.

- [`paper-scout/`](paper-scout/): the demo. Recent arXiv papers in Elasticsearch Serverless, Jina embeddings, keyword/semantic/hybrid search, an Agent Builder agent, and an Elastic Workflow. Setup takes about 5 minutes.
- [`slides/deck.html`](slides/deck.html): the workshop slides. Open the file in a browser, use the arrow keys to move between slides, and press `N` for speaker notes.
